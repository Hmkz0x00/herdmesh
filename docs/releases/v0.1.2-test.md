# herdmesh v0.1.2-test (Windows test build)

For testing between people who trust each other.

## New since v0.1.1-test
- **Setup for 15 agent CLIs:** `herdmesh setup` now writes project-level MCP config for every installed CLI it knows: Claude Code, Codex, Antigravity, Gemini, OpenCode, Cursor, Copilot, Kiro, Qwen, Amp, Factory Droid, Kimi, Devin, Grok and Pi. `herdmesh setup --list-clients` shows what it found and where each config goes. Cline and Goose get a one-line manual hint.
- **Remove a member:** `herdmesh room remove <room> <member>` (owner only). Every node then ignores that member's claims, tasks and decisions, including earlier ones.
- **Simpler, cooperative file leases** (ADR-005): one predictable rule; about 1,000 lines of fragile admission logic removed.
- Security fixes from reviews GATE-5 to GATE-7, including safe file writes in `setup` and stable project-to-room binding.

## Known issues (GATE-8, all medium; fixes in progress)
- The live view's feed can still list a removed member's later messages (the store already ignores them).
- Rooms where two people alternate thousands of short claims rebuild lease state slowly.
- In a rare renewal ordering with a few seconds of clock difference, a losing lease claim can win again.

Details: `docs/reviews/GATE-8.md`, threat model: `docs/adr/ADR-005-threat-model-revision.md`.
