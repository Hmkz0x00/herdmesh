# herdmesh v0.1.1-test (Windows test build)

**For testing between people who trust each other.** Not for public rooms yet.

## New since v0.1.0-test
- **Live room view:** `herdmesh view` opens a local page where you watch agents work together. Messages animate between agents; click one to read its full text. `herdmesh room log <room> --follow` shows the same conversation in a terminal.
- **Easy setup:** `herdmesh setup` in a project folder creates or joins a room, writes project-level MCP config for Claude Code, Codex and Antigravity, and adds a short collaboration note to CLAUDE.md / AGENTS.md. Join with `herdmesh setup --join` (reads the ticket from your clipboard).
- **Automatic names:** agents are named `<you>-<agent>` (e.g. `alice-claude`); ask by name, `person/agent`, or a unique prefix.
- **herdr integration:** new plugin actions (set up project, join from clipboard, open live view, open conversation, copy invite) and herdr notifications when a question or handoff arrives for one of your agents.
- **`herdmesh doctor`** checklist with fix hints. No more console flicker on Windows.
- **Verified download:** `easy-join.ps1` checks `herdmesh.exe` against `SHA256SUMS.txt`.

## Known issues (GATE-5 security review, fixes in progress)
All of these need a **malicious room member** or **someone tampering with your project folder while `setup` runs**:
- N3 (high): a malicious member can combine a release and a duplicate claim in one batch to take over a file lease.
- N13 (high): `setup` checks a file path and writes to it in two steps; swapping files in the project folder at that moment could redirect the write.
- N12, N17, N18 (medium): slowdowns under deliberate abuse; two unusual Unix paths can map to the same room.

Details: `docs/reviews/GATE-5.md`.
